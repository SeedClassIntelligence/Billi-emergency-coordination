Installing

Three steps, then you're protected

Billi isn't on the Play Store yet, so Android will ask you to confirm a couple of things it wouldn't ask for a store app. None of these warnings mean something is wrong.

01

Open and install

Open the downloaded file and tap Install anyway when Android warns about an unrecognized developer. That warning is standard for any app installed outside the Play Store.

02

Allow the permissions

On first launch, allow SMS, Location, Microphone and Camera. These aren't nice-to-haves — they are the four things Billi actually does when you trigger an emergency.

03

If SMS gets blocked

If Android blocks SMS "for your protection", go to Settings → Apps → Billi → ⋮ → Allow restricted settings, then allow SMS. This is an Android safeguard for sideloaded apps, not a Billi bug.

🧪 You're testing a live prototype — please read this part

GPS, microphone, camera and real SMS are genuinely active in this app. Nothing about them is simulated. That means a test trigger sends a real text message to a real phone.

  • Use your own real information — the product is only worth testing with real data.
  • Only add trusted contacts who have agreed in advance to receive a test alert.
  • Billi is not a replacement for 911 and is not a professionally monitored service. Nobody is watching a screen on your behalf.
