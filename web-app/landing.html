What Billi Actually Does

Not a feature roadmap — every item below is real and running right now.

🛰️ Real Device Sensing

Real GPS, motion, and audio capture through the browser or the native Android app.

🧠 Gemini AI Reasoning

Live context synthesis, risk analysis, and translation — with an honest deterministic fallback whenever live AI isn't available.

🔑 Nine Real Trigger Paths

Safe word, hold-to-activate, fall or crash detection, a duress PIN, and more — every path reaches the same protected response.

🗺️ Real Safe Zones

An actual interactive map with address search — click, drag, or search a building, not a slider and a guess.

📲 Real SMS Delivery

Sent through the phone's own SIM on Android, or a real carrier gateway for iOS and browser-only sessions.

👥 One account, work and family

Add a second device and it gets its own GPS, mic and camera, scoped to whoever it protects. Lone-worker tools stop at the worker. Family apps stop at the family. This doesn't.

🛡 AI recommends. The rules decide.

Gemini reads the live incident and suggests actions. A separate rule engine checks each one against the permissions you set, and only then approves it. Withhold audio consent and no model gets to override that.

🔄 Live Multi-Device Sync

Guardian, protected person, and responder sessions all see the same incident update in real time, on every device.

📱 Install Billi for Android

Not on the Play Store yet, so there are two extra taps.

  1. Open the downloaded file and tap Install anyway when Android warns about an unrecognized developer.
  2. On first launch, allow SMS, Location, Microphone and Camera — these are what Billi actually uses in an emergency.
  3. If SMS gets blocked: Settings → Apps → Billi → ⋮ → Allow restricted settings.

Requires Android. These steps stay available on the next page.
